# 🌸 MoodBloom

MoodBloom, kullanıcıların günlük ruh hâllerini takip etmelerini sağlayan bir web uygulamasıdır.

## Özellikler

- 😊 Günlük ruh hâli seçimi
- 📝 Günlük yazma ve kaydetme
- 📚 Geçmiş kayıtları görüntüleme
- 📊 Ruh hâli istatistikleri
- 📅 Takvim ile günlük takibi
- 💾 Verileri tarayıcıda saklama
- 📱 Mobil uyumlu tasarım

## Kullanılan Teknolojiler

- React
- JavaScript
- HTML
- CSS
- Vite
- LocalStorage

## Nasıl Çalıştırılır?

Terminali açıp şu komutları çalıştırın:

```bash
npm install
npm run dev
```
